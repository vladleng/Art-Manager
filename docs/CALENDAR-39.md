# #39 / 0.4.1 — текущее время, фокус и сохранение прокрутки дня

Первый срез #39 по решению пользователя 2026-11-14. Затрагивает только дневную панель календаря (`DayCalendarPanel`) и общий расчёт рабочего времени; модель, schema, планы задач, события, Undo/CAS и файл workspace не меняются.

## Контракт

- **Линия «сейчас».** Тонкая горизонтальная линия поперёк часовой сетки на текущей минуте дня (1 минута = 1 px). Рисуется только когда выбрана сегодняшняя дата; обновляется таймером раз в минуту и движется сверху вниз. Не перехватывает мышь, не участвует в hit-testing и не влияет на drag-and-drop.
- **Фокус при открытии.** При старте приложения и при переключении на сегодняшнюю дату календарь прокручивается так, что линия «сейчас» стоит на **1/3 высоты** видимой области. Другие даты открываются на 08:00.
- **Действия слева не двигают календарь.** Открытие задачи, смена страницы, поиск, фильтры и любые вызовы `WorkspaceShell::refresh()` не меняют вертикальную прокрутку: `refresh()`/`resized()` не вызывают `setViewPosition`, кроме первого реального layout.
- **Прокрутка пользователя сохраняется** в течение сессии (обновления, переключения страниц, изменение высоты «Весь день» в допустимых пределах). Смещение **не сохраняется между запусками**: после перезапуска фокус снова на текущем времени (решение пользователя 2026-11-14).
- **Линия просто уезжает** за границу видимой области при прокрутке — автопрокрутка за временем не реализуется (решение пользователя 2026-11-14).
- **Часовой пояс.** Пока используется тот же фиксированный UTC+7 (Asia/Krasnoyarsk), что и для «сегодня» в #38; IANA/DST — отдельный срез. Хелперы `workspaceToday`/`workspaceMinuteOfDay` в `TaskPlanning.h` — единственный источник этого расчёта.

## Изменения

- `src/TaskPlanning.h` — `workspaceToday`, `workspaceMinuteOfDay`, смещение UTC+7.
- `src/DayCalendarPanel.h/.cpp` — таймер на 15 с (перерисовка только при смене минуты), рисование линии, начальный фокус, `scrollToStartOfDay()`.
- `tests/TaskTreeUiTests.cpp` — расчёт минут/даты, фокус «сейчас» на 1/3, отсутствие сброса прокрутки при `refresh()`, старт с 08:00 для другой даты.

## Не входит
