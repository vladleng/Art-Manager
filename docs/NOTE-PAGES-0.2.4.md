# #63 / 0.2.4 — заметки, статусы подзадач и чёрная шапка

**Источник:** пожелания пользователя от 2026-11-01, родитель [#61](https://github.com/vladleng/Art-Manager/issues/61), принятая база 0.2.3 (`main`). **Статус:** только source-кандидат; CI, Windows GUI и пользовательская приёмка до проверки — NOT TESTED. **Не сливать в main до согласования.**

## Страницы

- Старые `WorkspacePage.kind=page` сохраняются без миграции и сразу показывают таблицу задач. Повторяющиеся вкладки «Содержимое / Задачи» удалены.
- Новый `WorkspacePage.kind=note` — самостоятельная «Заметка на полях», открывающая существующий блочный редактор. Создаётся кнопкой «+ Заметка» в панели либо через ПКМ страницы → «Новая вложенная заметка». Иерархия, имена, перемещение/архив/восстановление общие; названия заметок в навигации помечаются нейтральным значком.
- `WorkspacePage.blocks` у старых страниц **не изменяются и не удаляются**. Для существующего содержимого страницы: ПКМ на странице с блоками → «Открыть прежние материалы» (представление `pageBlocks:<id>`). Старые блоки можно править и сохранять по исходным UUID; при возврате на страницу снова показываются задачи.
- Формат остаётся workspace schema 2; поле `kind` уже существовало. Новых storage-файлов, ключей и миграции нет. JSON validation допускает только `page/note/song/dawFolder`.
- Задачи могут принадлежать только `page`, **не** `note`; перенос мышью/командой на заметку запрещён. В списке владельцев создания задач заметки не показываются. `note` может содержать вложенные страницы/заметки.

## Подзадачи

- У checkpoint-строк вместо checkbox квадратов нейтральный маркер; клик по бывшему чекбоксу ничего не переключает. `TODO/WIP/WAIT/DONE/...` меняются через существующий status pill. Данные status, IDs, Notes и прогресс сохраняются.
- Checkbox-блоки типа `checklist` внутри документов заметок **не менялись**.

## Окно

- Верхняя JUCE-панель имеет собственную заливку `#202123`, как тёмная шапка MR Live (не прежний olive/neutral widget background). Светлый текст, JUCE-оконные кнопки; корпус приложения, смысловые цвета статусов и приоритетов не изменяются.

## Приёмка

1. Создать страницу проекта и заметку на верхнем уровне; создать вложенную заметку, написать 1–2 блока, перезапустить приложение и проверить сохранение.
2. Открыть старую страницу с контентом: теперь по умолчанию список задач, старый текст через ПКМ «Открыть прежние материалы»; убедиться, что ID/блоки не потеряны.
3. Перенести/архивировать/восстановить страницу-заметку; проверить, что задачи нельзя создать на странице заметок.
4. Проверить чек-поинты: клик по нейтральному маркеру не переключает выполнение, статус-меню и прогресс работают. Чек-листы в заметках работают по-прежнему.
5. Проверить почти чёрную верхнюю панель, кнопки закрытия/сворачивания/максимизации, перетаскивание/двойной клик по заголовку на Windows и комфортный контраст/DPI.
6. Windows Actions версия 0.2.4 в run/app/manifest/artifact; профильные тесты `WorkspaceNavigationTests`, `TaskTreeUiTests`. Нет автоматической приёмки по PASS.

**Не входит:** новое компактное контекстное окно подробностей задач, нативный MR Live adapter, импорт/миграция старых page blocks в другие записи. Последнее будет отдельным явным действием с backup.
