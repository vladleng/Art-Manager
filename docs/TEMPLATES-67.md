## Работа в интерфейсе

- «+ Страница» и «Новая вложенная страница» открывают компактное меню: пустой/обычный проект, аранжировка, работа над треком, запись, сведение, публикация контента. Создание задачи предлагает простую задачу и музыкальные шаблоны с подзадачами.
- После выбора — небольшая панель с названием и, для задачи, страницей-владельцем. Enter создаёт, Esc/«Отмена»/закрытие панели отменяет. Новая задача остаётся в списке; полноэкранный TaskDetails не открывается. Ошибка записи сохраняет введённое название в открытой панели и не меняет навигацию.
- ПКМ по проекту или обычной задаче → «Сохранить как шаблон…». Захватываются активные задачи выбранной страницы или выбранная задача с потомками, свойства, Notes, описание и активные legacy checkpoints. Архивы не попадают в определение; исходные данные остаются нетронутыми. Вложенные страницы не захватываются.
- «+ Новый шаблон…», «Редактировать шаблон» и «Удалить шаблон» находятся в меню создания. В редакторе применяется существующий TaskTree: двойной клик по названию/Notes, статусы/приоритеты, раскрытие, ПКМ и добавление подзадач. «+ Задача» добавляет корневую задачу проекта или потомка корневой задачи шаблона. Корень шаблона задачи нельзя архивировать. Имя шаблона задаётся сверху. Сохранение явно; закрытие отменяет черновик. Встроенные примеры неизменяемые, пользовательские можно создавать на их основе через проект/задачу.
- При наведении на enabled пункт меню яркость текста не меняется; серый фон сохраняется. В sidebar отрисовка рамки drag-target больше не меняет цвет текста.

## Контракт хранения

Workspace schema **2 не меняется**. Шаблоны — отдельные detached определения в `Art Manager.templates.json` рядом с workspace. Формат `ArtManagerTemplates`, version 1, каждый элемент содержит тип проекта/задачи и валидируемый изолированный WorkspaceModel с одной страницей. Это не source reference и не задача в общем списке. Изменение определения не меняет ранее созданные проекты.

Каталог проверяет формат, версию, IDs, дерево, владельца, архивы и ровно один корень шаблона задачи. Загрузка сначала проверяет весь документ. Сохранение проверяет внешнее изменение, пишет предыдущую точную версию в `.backup`, использует временный файл и проверяет запись перед заменой. Повреждённый/будущий формат не сбрасывается; встроенные шаблоны остаются доступны, запись пользовательских определений блокируется. Автоматическое восстановление/импорт каталога не входит в #67.

`WorkspaceCommands::createFromTemplate` проверяет определение, создаёт новые IDs страницы/задач/блоков/checkpoints и переназначает parent/owner IDs. Существующие записи, статусы, порядок и архивы не меняются. Применение через WorkspaceController — одна транзакция и существующий persistent Undo/Redo, backup и revision guard. При ошибке нет частично добавленного проекта. Никаких MR Live/Studio, сетевых ассетов или внешних файлов.

`TaskTreeUiTests`: равенство обычного и highlighted текста при сохранённом сером фоне; изолированное открытие редактора; snapshots 100/125/150/200%; черновик создания после ошибки. Существующие тесты TaskTree покрывают inline ввод, клавиатуру/фокус, Notes, подзадачи и ошибки записи. Снимки `template-editor.png` и `template-create.png` включаются в пакет.

Windows Actions сохраняет обязательные прежние проверки и добавляет WorkspaceTemplateTests. Версия CMake/EXE/run/package/manifest — 0.2.6. Физический DPI, реальное меню мышью/клавиатурой и UX принимаются пользователем; автоматические component snapshots не равны интерактивной приёмке.

## Чек-лист приёмки Windows

1. Создать обычный и музыкальный проекты, затем музыкальную задачу; отменить создание и проверить отсутствие лишних записей.
2. Сохранить свой проект и задачу как шаблоны, изменить названия/Notes/статусы/подзадачи, сохранить и перезапустить приложение.
3. Применить шаблон дважды: независимые новые задачи, исходный проект не меняется. Изменить один экземпляр и проверить второй.
4. Workspace → Undo/Redo отменяет/возвращает всё применение шаблона.
5. Проверить gray hover при одинаковой яркости букв, ПКМ, Enter/Esc, фокус и компактность на своём DPI.

#68 и закрытие родительских #37/#55 этим кандидатом не выполняются.
