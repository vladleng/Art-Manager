# #68 / 0.2.7 — Portable workspace, import conflicts, legacy materials

## Контракт реализации

- **Формат:** `ArtManagerPortable`, `schemaVersion: 1`, `sourceWorkspaceId`, `selection`, `contents` (строгий self-contained snapshot Workspace schema 2). Это транспортный пакет, **не** новый формат живого `Arranger Manager.workspace.json`. Версия неизвестна — импорт отклоняется.
- **Экспорт:** из `Workspace → Экспорт локального рабочего пространства`, из контекстного меню страницы или задачи. `all-local` включает все локальные страницы/заметки/общие задачи, включая архивы, Notes, status/P1-P4, hierarchy, blocks, checkpoint IDs, порядок. `page:<id>` экспортирует страницу и её локальных потомков с принадлежащими задачами. `task:<id>` экспортирует выбранную задачу и вложенные задачи, добавляя пустую page-заглушку-владельца; чужие задачи и блоки этой страницы не попадают в пакет.
- Исторические `catalog` / `.song` / DAW-пути, внешние медиа и секреты **не экспортируются и не импортируются**. Экспорт производится локально через проверенную временную запись с атомарной заменой выбранного файла. Предпросмотр с количеством объектов обязателен перед выбором места сохранения.
- **Импорт:** кнопка в меню `Workspace`. Парсер проверяет формат, схему, структуру, ссылки на владельцев/родителей и ID; не меняет живое состояние при ошибке. Перед подтверждением показываются counts и число совпадающих ID. Для пакета без конфликтов: сохранить исходные ID или создать копии. При конфликте: **только копии** или отмена — без silent overwrite. Копирование переназначает одновременно все IDs (page, task, block, checkpoint) и owner/parent связи, Notes/архивы/порядок неизменны. В любом случае импорт исполняется через `WorkspaceController.execute → WorkspaceCommands.importPortable → WorkspaceStore.save`, поэтому применяется одной транзакцией с ревизией, CAS, backup и Undo.
- **Legacy blocks:** ПКМ локальной страницы с `page.blocks` → `Перенести прежние материалы в заметку…`. После подтверждения `moveLegacyBlocksToNote` переносит ровно те же экземпляры блоков с теми же IDs и текстом в новую дочернюю заметку. Оригинальная страница остаётся, её `blocks` пустеют. Ошибка записи/валидации откатывает всю команду, старый workspace не меняется; Undo/Redo поддерживается.
- **Recovery:** существующая кнопка `Restore previous workspace backup...` в меню Workspace с сохранением текущего файла под `before-restore`, проверкой схемы, повторным открытием. Перенос не вводит скрытую миграцию при запуске.
